# Changelog

All notable changes to this project are documented here.

Per-package changelogs are generated by release-plz under
`crates/koanf-core/CHANGELOG.md` and `crates/koanf-rs/CHANGELOG.md`.

## [Unreleased]

### Fixed

- directory and glob watchers reload on any change under the watched tree, so
  coalesced macOS FSEvents notifications are not missed
- directory watchers use the canonical path so FSEvents does not drop events
  for symlinked roots such as macOS temporary directories
- allow the permissive BSD and CDLA licenses used by HTTP compression and
  certificate dependencies in `cargo-deny`

## [0.1.0] - 2026-11-21

Initial release.

### Added

- Layered configuration with deterministic precedence and atomic rebuilds.
- Ordered `Value`/`Map` model with JSON, TOML, and YAML formats, plus optional
  JSON5, HCL, dotenv, INI, and RON parsers and renderers where supported.
- Typed serde access: `deserialize`, `get`, `get_opt`, `get_or`, and
  `Section` views.
- `KoanfSchema` derives for typed schemas, secret-path discovery, and schema
  validation.
- Numeric array-index reads such as `servers.0.host`.
- Type-directed scalar coercion with a strict opt-out.
- Sources: `Memory`/`ConfMap`, `Structs` (typed defaults), `Bytes`, `File`,
  `dir::Dir`, `glob::Glob`, `Env`, `Args`, conditional HTTP(S), Consul KV, and
  Vault KV.
- Directory sources with deterministic filename layering and optional
  recursive traversal.
- Glob-pattern sources with recursive matching and watching.
- Runtime overrides via `set`/`delete` that survive `reload`.
- Runtime source inspection and removal (`source_names` / `remove_source`),
  with custom `.named(...)` source labels.
- Configurable snapshot validation hooks that reject invalid rebuilds.
- Path-based debug redaction for snapshots, change sets, and watch events.
- Optional `tracing` instrumentation for loads, reloads, and watch errors.
- Async source loading via `AsyncSource`, `build_async`, and `load_async`.
- Optional atomic configuration saves through the `atomic-save` feature.
- File and directory watching with full rebuilds, change sets, and
  last-known-good snapshots, including a runtime-agnostic async stream.
- Snapshot and section rendering back to JSON, TOML, and YAML, plus rendered
  file saves that leave the target untouched on format errors.
- `Source`, `Format`, and `Watchable` extension traits.
- `no_std` support in `koanf-core` (with `alloc`), verified on
  `thumbv7em-none-eabihf`, and WebAssembly builds for the `koanf-rs` facade.
- Feature-gated facade with `koanf-core` as the extension-facing engine.
- Bilingual README, examples, CI, and Apache-2.0 licensing.
